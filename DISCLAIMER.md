For anything that matters, read the official publication. Every document
records the URL and SHA-256 of the source it was built from.

**What the verification does and does not prove.** The checks prove that no
content was invented and none was lost: the token stream of the output matches
the token stream of the source, section by section. They do **not** prove
correct reading order, they do not prove a value in a table is still in its
original row, and they say nothing about whether the original document is
itself correct. Sections where structure cannot be machine-verified are marked
Low confidence in each document's report.

**English only.** The source documents are trilingual. Sinhala and Tamil are
set in legacy non-Unicode fonts that do not extract as recoverable text, so
only the English text is reproduced. This is a limitation of the sources, not
an editorial choice, and it means the corpus is not a complete rendering of any
document.
